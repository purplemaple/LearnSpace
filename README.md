# LearnSpace

这是我的个人编程知识库，主要记录 C#、WPF、XAML、.NET 异步、多线程、设计模式、数据库等方向的学习笔记与配套示例代码。

## 目录说明

- `Code`：示例代码，通常按学习主题拆成多个小工程
- `Note`：Markdown 笔记，路径大体与 `Code` 中的示例代码对应
- `Resume`：简历相关资料

## 整理原则

这个仓库的笔记更偏个人复盘，不追求写成百科式教程。整理时应保留“问题背景、方案尝试、风险判断、最终结论”的脉络。

后续如果使用 Agent 辅助整理本文档库，请以根目录 [AGENTS.md](./AGENTS.md) 为唯一执行基准。
