
## 1. 问题背景

异步任务中需要控制并发以确保线程安全

---
## 2. 总结

 1. await Task ：Task 本身即可 await 来控制并发，源生。
 2. SemaphoreSlim ：可以具体设置并发数量，源生。
 3. TaskCompletionSource : 一次性锁，且可以携带返回值，源生。
 4. AsyncAutoResetEvent ：能够自动 reset 的锁，需要导入第三方包。
 5. AsyncLock ：能够在异步方法中使用 lock 语句（这个锁可以同时用在同步和异步方法中），需要导入第三方包。

结语：
> 在异步编程中使用同步机制更多是思想转变，
> 在传统多线程中，Thread 之间没有关联，也不太能在一个 Thread 中观测另一个 Thread 的状态，因此需要各种锁来保护共享资源，控制线程的执行顺序等。 
>  而在异步编程中，可以通过 await 来等待另一个 Task 的完成，不需要显式的锁来控制并发。

## 3.  方案一：AsyncLock

对应示例：[1_AsyncLock/Program.cs](../../../Code/CSharp进阶/多线程与异步/7_在异步任务中实现同步机制及使用信号量/1_AsyncLock/Program.cs)

### AsyncLock 是一个异步锁，允许在异步方法中使用 lock 语句来控制并发（这个锁可以同时用在同步和异步方法中）。

**需要导入 Nito.AsyncEx 包**

典型写法：

```csharp
class Demo
{
    readonly AsyncLock _lock = new();

    readonly CancellationTokenSource _cts = new();

    public async Task DoJobAsync()
    {
        //AsyncLock 也可以被取消
        using (await _lock.LockAsync(_cts.Token))
        {
            //AsyncLock 本身仍然可以使用同步锁，因此在这也可以写同步语句
            _lock.Lock();
        }
    }
}
```

调用者：

```csharp
static async Task Main(string[] args)
{
    var demo = new Demo();
    await demo.DoJobAsync();
}
```

简单示例：

```csharp

class TestDemo
{
    AsyncLock asyncLock = new();

    DateTime start = DateTime.Now;

    List<Task<int>> tasks = [];

    public TestDemo()
    {
        // 创建多个异步任务来计算整数的平方，但这里使用异步锁确保同一时间只有一个异步任务执行
        tasks = Enumerable.Range(1, 10).Select(x => ComputeAsync(x, asyncLock)).ToList();
    }

    /// <summary>
    /// 异步计算指定整数的平方，并在计算过程中使用异步锁确保线程安全。
    /// </summary>
    /// <remarks>This method acquires the specified asynchronous lock before performing the computation. Use
    /// this method when thread-safe access is required in asynchronous scenarios.</remarks>
    public async Task<int> ComputeAsync(int x, AsyncLock asyncLock)
    {
        using (await asyncLock.LockAsync())
        {
            await Task.Delay(300);
            return x * x;
        }
    }

    public async Task Run()
    {
        var results = await Task.WhenAll(tasks);
        Console.WriteLine(string.Join(", ", results));

        var end = DateTime.Now;
        Console.WriteLine($"Elapsed: {(end - start).TotalMilliseconds:F4} ms");
    }
}

internal class Program
{
    static async Task Main(string[] args)
    {
        var testDemo = new TestDemo();
        await testDemo.Run();
    }
}
```
结果需要3000毫秒以上，证明异步锁发挥作用

## 4. 方案二：SemaphoreSlim

对应示例：[2_SemaphoreSlim/Program.cs](../../../Code/CSharp进阶/多线程与异步/7_在异步任务中实现同步机制及使用信号量/2_SemaphoreSlim/Program.cs)

### SemaphoreSlim 是一个轻量级的信号量，允许在异步方法中自由设置具体可以有多少个线程并发访问
 
 简单示例：
 
```csharp
class TestDemo
{
    SemaphoreSlim semaphoreSlim = new(3,3); //可以自由设置初始几个线程，最大几个线程同时进行（并非无限大，与CPU有关）

    DateTime start = DateTime.Now;

    List<Task<int>> tasks = [];

    public TestDemo()
    {
        // 创建多个异步任务来计算整数的平方，但这里使用异步锁确保同一时间只有一个异步任务执行
        tasks = Enumerable.Range(1, 10).Select(x => ComputeAsync(x, semaphoreSlim)).ToList();
    }

    /// <summary>
    /// 异步计算指定整数的平方，并在计算过程中使用异步锁确保线程安全。
    /// </summary>
    /// <remarks>This method acquires the specified asynchronous lock before performing the computation. Use
    /// this method when thread-safe access is required in asynchronous scenarios.</remarks>
    public async Task<int> ComputeAsync(int x, SemaphoreSlim semaphoreSlim)
    {
        //等待获取信号量
        await semaphoreSlim.WaitAsync();
        await Task.Delay(300); // 模拟一些异步工作
        semaphoreSlim.Release();
        return x * x;
    }

    public async Task Run()
    {
        var results = await Task.WhenAll(tasks);
        Console.WriteLine(string.Join(", ", results));

        var end = DateTime.Now;
        Console.WriteLine($"Elapsed: {(end - start).TotalMilliseconds:F4} ms");
    }
}
```

调用者：

```csharp
static async Task Main(string[] args)
{
    var testDemo = new TestDemo();
    await testDemo.Run();
}
```

结果需要1000毫秒以上，证明同时又3个线程执行

## 5. 方案三：AsyncAutoResetEvent

对应示例：[3_AsyncAutoResetEvent/Program.cs](../../../Code/CSharp进阶/多线程与异步/7_在异步任务中实现同步机制及使用信号量/3_AsyncAutoResetEvent/Program.cs)

### AsyncAutoResetEvent 是一个异步自动重置事件，允许在异步方法中使用 AutoResetEvent 来控制线程的执行顺序。

注：
1. 每次获取锁后会自动 reset 上锁。除非再次 set 解锁，否则后续的调用者将一直等待。
2. 需要导入 Nito.AsyncEx 或 Microsoft.VisualStudio.Threading 包（构造稍有不同）

源码：
[Nito.AsyncEx.AsyncAutoResetEvent](https://github.com/StephenCleary/AsyncEx/blob/master/src/Nito.AsyncEx.Coordination/AsyncAutoResetEvent.cs)

[Microsoft.VisualStudio.Threading.AsyncAutoResetEvent](https://github.com/microsoft/vs-threading/blob/main/src/Microsoft.VisualStudio.Threading/AsyncAutoResetEvent.cs)

简单示例：

```csharp
static async Task Main(string[] args)
{
    var signal = new AsyncAutoResetEvent(false);

    var setter = Task.Run(async () =>
    {
        Console.WriteLine("Setter is waiting for 2 seconds...");
        await Task.Delay(2000);
        Console.WriteLine("Setter is setting the signal.");
        //释放锁
        signal.Set();
    });

    var waiter = Task.Run(async () =>
    {
        Console.WriteLine("Waiter is waiting for the signal...");
        //获取锁，同时 AsyncAutoResetEvent 会自动 reset 上锁，除非再次调用 Set 方法，否则后续的调用者将一直等待
        await signal.WaitAsync();
        Console.WriteLine("Waiter received the signal!");

        await signal.WaitAsync();
	    Console.WriteLine("test 永久等待"); //这条语句永久无法执行
    });

    await Task.WhenAll(setter, waiter);
}
```

## 6. 方案4：TaskCompletionSource

对应示例：[4_TaskCompletionSource/Program.cs](../../../Code/CSharp进阶/多线程与异步/7_在异步任务中实现同步机制及使用信号量/4_TaskCompletionSource/Program.cs)

### TaskCompletionSource 内部维护了一个只读 Task 对象，外部通过 await 这个 Task 控制并发，而内部通过 SetResult、SetException 或 SetCanceled 方法来设置这个 Task 的状态。

注：
1. Task 不能多次完成，因此这是一次性异步锁。同时 TaskCompletionSource 也不能多次设置结果，否则会抛出 InvalidOperationException 异常。
2. 使用 TrySetResult、TrySetException 和 TrySetCanceled 方法，避免多次设置结果时抛出异常。
3. TaskCompletionSource 可以携带返回值

简单示例：

```csharp
static async Task Main(string[] args)
{
    /*
     * TaskCompletionSource 内部维护了一个只读 Task 对象，外部通过 await 这个 Task 控制并发，而内部通过 SetResult、SetException 或 SetCanceled 方法来设置这个 Task 的状态。
     * 注：
     *      1. Task 不能多次完成，因此这是一次性异步锁。同时 TaskCompletionSource 也不能多次设置结果，否则会抛出 InvalidOperationException 异常。
     *      2. 使用 TrySetResult、TrySetException 和 TrySetCanceled 方法，避免多次设置结果时抛出异常。
     *      3. TaskCompletionSource 可以携带返回值
     * 
     */
    var tcs = new TaskCompletionSource();
    var tcsStr = new TaskCompletionSource<string>();

    var setter = Task.Run(async () =>
    {
        Console.WriteLine("Setter is waiting for 2 seconds...");
        await Task.Delay(2000);
        Console.WriteLine("Setter is setting the result.");
        tcs.SetResult();
        tcsStr.SetResult("Mission Completed!");     //携带返回值

        //防止多次设置结果导致 InvalidOperationException 异常
        if (!tcs.TrySetResult())
        {
            Console.WriteLine("tcs is Already set!");
        }
    });

    var waiter = Task.Run(async () =>
    {
        Console.WriteLine("Waiter is waiting for the result...");
        await tcs.Task;
        Console.WriteLine("Waiter received the result!");
        string res = await tcsStr.Task;             //等待并获取返回值
        Console.WriteLine(res);
    });

    await Task.WhenAll(setter, waiter);
}
```

## 7. 方案五：Task

对应示例：[5_Task/Program.cs](../../../Code/CSharp进阶/多线程与异步/7_在异步任务中实现同步机制及使用信号量/5_Task/Program.cs)

### Task 作为一个异步任务，本身就可以 await 来控制并发，并且可以多次 await 同一个 Task

简单示例：

```csharp
static async Task Main(string[] args)
{
    var setter = Task.Run(async () =>
    {
        Console.WriteLine("Setter is waiting for 2 seconds...");
        await Task.Delay(2000);
        Console.WriteLine("Setter is setting the result.");
    });

    var waiter = Task.Run(async () =>
    {
        Console.WriteLine("Waiter1 is waiting for the result...");
        //直接等待 setter 即可
        await setter;
        Console.WriteLine("Waiter1 received the result!");
    });

    await Task.WhenAll(setter, waiter);
}
```
