# 查漏补缺

## 已掌握的基础与进阶知识
- C# 语言特性：访问修饰符、partial/ sealed、枚举、值/引用类型、装箱/拆箱、序列化/反序列化等内容形成了完整语法链路（参见 Note/C#基础 目录）。
- 面向对象与设计模式：继承、多态、抽象类/接口以及配套练习，辅以简单工厂设计模式和七大原则/23种模式的笔记，支持你在项目中进行模块化重构。
- 集合与字符串：ArrayList/List/Dictionary/HashTable、string 的拆分、连接、匹配等高级用法已经形成可复用经验。
- 多线程与异步：包含线程生命周期、锁、Monitor、Semaphore、Task/async/await、ConfigureAwait、CancellationToken、PLINQ 等内容，在多线程/异步项目中有知识支撑。
- WPF 基础：依赖属性、附加属性的定义与实战、绑定、Style/Trigger 等，为实现复杂 UI 提供底层理解。
- LINQ、ASP.NET Core DI：多种 LINQ 模式、延迟执行、并行查询、DI 的基本概念为业务逻辑层提供支撑。
